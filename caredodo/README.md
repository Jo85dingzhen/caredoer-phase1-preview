# CareDoDo desktop preview

Static demonstration of non-medical companionship, daily assistance and light housekeeping. English and Chinese pages share the same service and ZIP-code flows.

All coverage, prices and service arrangements remain examples or pending confirmation. Forms do not send or store personal information on this public preview. The CareDoer link opens the separate training preview.

No build is required. GitHub Pages serves this directory from the existing repository. See assets/photos/CREDITS.md and the font license files for asset credits.
